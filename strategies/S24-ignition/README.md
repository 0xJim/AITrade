## 策略逻辑

### 信号触发（4 个条件全部满足）

| # | 条件 | 默认值 | 说明 |
|---|------|--------|------|
| 1 | 15m 收盘涨幅 ≥ threshold | 1.2% | 捕捉瞬间点火动量 |
| 2 | 1h EMA9 > EMA21 | — | 要求上升趋势，用**前一根已收盘** 1h K 线判断 |
| 3 | 15m RSI ≥ 50 | 50 | 排除超买反弹 |
| 4 | 信号质量分 ≥ 70 | 70 | 综合动量强度 / 成交量 / ATR / K 线形态的 0-100 分 |

入场：**下一根 15m 开盘价**（非信号 K 线，避免追高）

### 整点过滤（hour_only）

生产配置启用 `--hour-only`：**仅交易每小时第一根 15m K 线**（开盘时间为 XX:00）。

原理：整点开盘时机构算法重置挂单，成交量有系统性峰值，信号的延续概率更高。实测 WR 从 46% 提升至 48.4%，DD 从 19% 降至 10.5%。

### 仓位分配（质量分加权）

| 质量分 | 仓位比例 | 说明 |
|--------|---------|------|
| 70–79 | 7% | 基础仓位 |
| 80–89 | 10% | 中等仓位 |
| 90+ | 15% | 满仓 |

> 杠杆 3x，最大同时持仓 3 个

### 退出规则

| 方式 | 触发条件 |
|------|---------|
| 止损 | ATR × 1.5，区间 [3%, 9%] |
| 止盈 | 止损 × 2.5（R/R = 2.5） |
| 超时 | 持仓满 4 小时按市价平 |
| 冷却 | 同 symbol 平仓后 4 小时内不再开仓 |

## 使用方法

### 依赖

```bash
python3 >= 3.10   # 无额外依赖，仅标准库
```

### 基础回测

```bash
# 生产配置（推荐）
python3 backtest_ignition.py \
  --days 365 \
  --hour-only \
  --sym-cap 5 \
  --exclude BUSDT,BILLUSDT,BNBUSDT,LINKUSDT,SAGAUSDT

# 自定义参数
python3 backtest_ignition.py \
  --days 90 \
  --threshold 0.015 \
  --quality 80 \
  --label my_test
```

### 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--days` | 365 | 回测天数 |
| `--threshold` | 0.012 | 15m 涨幅门槛（1.2%） |
| `--quality` | 70 | 最低质量分 |
| `--rsi` | 50 | 最低 RSI |
| `--hold` | 4 | 最大持仓小时数 |
| `--tp-ratio` | 2.5 | 止盈/止损倍率 |
| `--sym-cap` | 4 | 单 symbol 每 7 天最多开仓次数（0=不限）|
| `--hour-only` | — | 只交易整点开盘的 15m 信号 |
| `--dynamic` | — | 启用动态黑名单规则（实验性）|
| `--exclude` | — | 排除 symbol，逗号分隔 |
| `--symbols` | — | 指定 symbol 池，默认使用 COMMON_SYMBOLS |
| `--label` | baseline | 输出文件名标签 |
| `--no-save` | — | 不保存 JSON 结果 |

### 质量分计算（0-100）

| 维度 | 权重 | 说明 |
|------|------|------|
| 涨幅强度 | 0–35 | 相对 threshold 的超额涨幅 |
| 成交量倍数 | 0–30 | 当根成交量 / 近 10 根均量 |
| ATR 适中性 | 0–20 | ATR/Price ∈ [0.5%, 4%] 得满分 |
| K 线实体比 | 0–15 | 实体/振幅（越大动量越纯） |

## 重要技术说明

### EMA 时序修复（v3）

原始实现存在轻微前视偏差：对整点开盘的 15m 信号，EMA 确认使用了当前尚未收盘的 1h K 线。v3 修复为始终使用**前一根已收盘**的 1h 信号：

```python
prev_1h = (candle.time // MS_1H) * MS_1H - MS_1H
bullish  = ema_bullish_at.get(prev_1h)
```

修复后信号量从 ~700 增至 ~1200+，但 DD 同步上升。整点过滤（`--hour-only`）在无前视的条件下重建了原有的信号质量。

### 动态黑名单（实验性，未纳入生产）

| Rule | 触发条件 | 冷却 |
|------|---------|------|
| Rule 1 | 近 10 笔亏损 ≥ 8 笔 | 7 天 |
| Rule 2 | 近 10 笔 PF < 0.8 | 14 天 |
| Rule 3 | 近 7 天单币亏损 > -3% 余额 | 14 天 |
| Rule 4 | 当日总亏损 > -3% 余额 | 当天停止 |

测试表明动态规则有效降低 DD（10.4%），但因反应滞后导致 ROI 大幅下滑（147%），未纳入生产配置。
