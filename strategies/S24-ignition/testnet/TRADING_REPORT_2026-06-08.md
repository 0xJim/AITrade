## 四、Bug 修复记录（v5，2026-06-08）

### 问题：testnet 不支持条件单，导致每次开仓后立即应急平仓

**现象：**
- `STOP_MARKET` / `TAKE_PROFIT_MARKET` 通过 `/fapi/v1/order` 下单返回 **-4120** 错误
- Algo API（`/fapi/v1/order/algo`）在 testnet 返回 **404**
- sl_ok / tp_ok 均为 False → 触发"保护单失败 → 立即市价平仓"
- v5 运行期间（14:01~15:23 CST）VVVUSDT 连续 4 笔开+平，损耗 **-1.77 USDT**（手续费+滑点）

**影响范围：** 仅 v5 部署后（06-08 14:01）至修复（15:23）的约 82 分钟，共 4 笔 VVVUSDT 交易。06-06~06-07 的旧版本交易不受此 bug 影响。

### 修复方案：软件止损/止盈

`check_positions`（s24_trader.py L574-577）已实现软件 SL/TP 检查（每轮扫 15m K 线 low/high）。只需让开仓阶段挂单在 testnet 上返回占位成功即可。

**`binance_api.py` 修改：**

```python
from config import ..., BINANCE_TESTNET   # 新增 import

def place_stop_loss_order(symbol, quantity, direction, stop_price):
    if BINANCE_TESTNET:
        return {"orderId": "software_sl", "status": "NEW", "software": True}
    # 实盘：正常下 STOP_MARKET 单 ...

def place_take_profit_order(symbol, quantity, direction, tp_price):  # 新增函数
    if BINANCE_TESTNET:
        return {"orderId": "software_tp", "status": "NEW", "software": True}
    # 实盘：正常下 TAKE_PROFIT_MARKET 单 ...
```

**`s24_trader.py` 修改：**

```python

# TP 下单由内联 place_order(..., "TAKE_PROFIT_MARKET") 改为：
tp_result = place_take_profit_order(sym, quantity, "long", tp_price)
```

**验证：**

```

```
