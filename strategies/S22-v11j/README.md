## 策略判断

**v11j不是收益增强策略，而是风险控制层。** 它通过开仓前的估算风险上限缩小仓位，盈利单和亏损单都会被等比例缩小，所以旧版 `+$11,462 / DD10.56% / ROI-DD108.6` 是无效结论，不能再用于策略选择。

当前更稳妥的解释是：方案M把尾部单笔亏损压到约 $40，但牺牲了盈利弹性；如果目标是 testnet 小资金冷启动，M可以作为保守挡位。如果目标是收益/回撤折中，应优先继续比较 L / D / G / M。

短期不建议把纯 M `$40` 当“最优收益方案”。推荐顺序：

1. **L**: 最干净的收益/回撤比，适合优先复核。
2. **G/D**: `$60` 风险上限比 `$40` 更像收益和风控的折中。
3. **M**: 适合小资金或 testnet 冷启动的保守风控挡位。

## 正确风控逻辑

开仓前先按当前仓位估算风险，再统一缩仓。这个缩仓发生在 PnL 计算之前，因此盈利单也会被缩小：

```python
est_risk = position_usd * signal_sl_pct_raw * leverage * mult
if est_risk > max_loss_per_trade:
    shrink_ratio = max_loss_per_trade / est_risk
    mult *= shrink_ratio

pnl = raw_pnl * mult
```

不要使用 `raw_pnl < 0` 作为缩仓条件；那会重新变成“只截亏损单、盈利不缩仓”的未来函数。
