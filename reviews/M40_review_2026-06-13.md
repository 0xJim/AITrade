## 六、问题与异常记录

### 6.1 🔴 致命问题：止损单100%失败

**现象：** 全部15笔实盘交易的 STOP_MARKET 订单均返回 Binance API 错误。

```
错误代码: -4120
错误信息: "Order type not supported for this endpoint. 
          Please use the Algo Order API endpoints instead."
```

**影响：**
- 止损单无法挂单，系统依赖软件层面轮询止损
- 移动止盈功能勉强正常（软件层实现）
- 24笔"同步平仓（交易所无持仓）"说明大量模拟交易在交易所根本没有实际成交
- 若cron任务中断或服务器宕机，持仓将无止损保护

**根因分析：** Testnet 环境对 STOP_MARKET 订单类型的支持与 Production 不同，需要使用不同的API端点或参数。

### 6.2 🟡 "同步平仓"现象严重

24/35 笔已平仓交易（68.6%）以"同步平仓（交易所无持仓）"方式退出，这些交易在开仓后2-3分钟内就被立即平掉。

**含义：** 系统检测到交易所端无对应持仓后自动清理本地记录。多数为模拟交易（`_simulated: true`），实际未在交易所开仓。

### 6.3 🟡 IDUSDT 连续交易矛盾

IDUSDT 出现两笔截然不同的结果：
- #022: +6.78U（extreme_neg_funding, 移动止盈）✅
- #029: -10.69U（extreme_neg_funding, 止损）❌

同一信号类型同一方向，一天内反向结果，说明信号重复触发的风控缺失。

### 6.4 🟡 WLDUSDT 重复开仓

WLDUSDT 做多被触发两次（#007 和 #023），两次均止损，合计亏损 -9.74U。

### 6.5 🟢 做空信号被严重低估

做空方向胜率80%，但系统接受的信号中做空仅占27%。防守模式中存在大量"防守模式暂停 closed_15m_spike long"（7,982次），说明做多信号被过度优先化或做空信号触发条件过严。

### 6.6 🟢 动态黑名单为空

```
"symbols": [],
"quarantine": {}
```

运行4天，虽然有多笔大额亏损，但没有任何币种被动态拉黑。黑名单机制可能未生效或触发条件过松。

## 七、改进建议

### 7.1 🚨 紧急修复（P0）

1. **修复止损单挂单功能**
   - 问题：Testnet 不支持当前使用的 STOP_MARKET 订单类型
   - 方案：改用 conditional order API endpoint，或切换到 `STOP` 订单类型
   - 验证：修复后在 testnet 单独测试挂单成功后再恢复交易

2. **添加持仓安全检查**
   - 若止损单无法挂出，应立即在系统层启用更密集的止损轮询（每10秒检查一次持仓价格 vs 止损线）
   - 在开仓失败时发送告警通知

### 7.2 ⚡ 高优先级改进（P1）

3. **调整做多/做空信号权重**
   - 当前做多亏损 -21.83U（胜率40%），做空盈利 +0.70U（胜率80%）
   - 建议：在做多信号上提高信号质量门槛至60+，或增加额外过滤条件
   - 考虑在防守模式下也暂停部分 long 信号（当前防守模式仅暂停 closed_15m_spike long）

4. **修复重复信号触发**
   - 同一币对（WLDUSDT、IDUSDT）被多次触发同一方向信号
   - 建议：同一币对+方向信号冷却时间从4小时延长至12小时
   - 对于已止损的币对，应自动加入动态冷却24-48小时

5. **启用动态黑名单**
   - 当前黑名单为空，需要检查黑名单规则是否正常触发
   - 建议：单笔亏损 >$5 的币对自动进入48小时冷却

### 7.3 📊 中优先级优化（P2）

6. **优化极端负费率信号**
   - `extreme_neg_funding` 总盈亏 +8.09U（5笔中3笔盈利），表现优于主流的 `oi_surge`（-13.80U/28笔）
   - 建议：适当增加 extreme_neg_funding 信号的接受率

7. **改进移动止盈参数**
   - 当前移动止盈效果不错（4笔共 +10.80U），但"高点回撤4.0%"的阈值偏大
   - 建议测试3.0%回撤阈值，可能锁定更多利润

8. **同步平仓处理优化**
   - 24笔"同步平仓"交易中22笔为模拟交易，说明仓位计算与交易所实际状态存在偏差
   - 建议增加开仓后的确认机制，避免记录无效交易

### 7.4 🔬 长期建议（P3）

9. **积累更多样本数据**
   - 当前37笔交易样本量偏小，统计结论参考价值有限
   - 建议持续运行至少2周以上再做策略调整

10. **考虑关闭模拟交易记录**
    - 模拟交易混淆了实际盈亏统计（22笔模拟 vs 15笔实盘）
    - 建议单独统计实盘表现，或关闭模拟交易功能
